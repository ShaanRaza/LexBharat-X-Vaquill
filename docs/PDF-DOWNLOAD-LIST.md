# India Code PDFs to download (group B: Act text we cannot fill from the dataset)

**What this is.** The Acts below are stubs, missing, short of sections, or have Schedules / Forms / Appendices we do not hold. Each needs the Act's own PDF from India Code (https://www.indiacode.nic.in), saved into `content/supplement/pdfs/` under the exact file name given. Then the same extractor used for the Contract Act, CPC, Limitation, Stamp and the Constitution (`scripts/supplement/`) fills the missing sections and Schedule units, word-by-word checked against the PDF.

**Rules.** Download by hand, in your browser (the site refuses automated downloads, and we do not work around that). Take the **"as on" / latest** PDF of the Act, not a bare/original-as-enacted version, unless the row says otherwise. Do not edit the PDF. One PDF per Act. Priority 1 = most used by practising lawyers. Max 40 Acts (this list has 40 rows).

**How to find each Act on India Code.** Search by the exact title below (the title as India Code prints it), or use the Act-year filter / enactment-date filter with the range in the "Date filter" column (enactment date from – to; the Act number is shown in brackets for checking you opened the right one). Open the Act, then the PDF link (the "Act as a whole" PDF, not a single section).
