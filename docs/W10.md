## Item 10: Supreme Court full text, measurements

A retrieval test with a voyage-4 query returned on-topic judgments (cheque limitation question), so the vectors are in the same space; stored vectors match a fresh voyage-4 embedding of the stored text at cosine 0.92–0.95 (same model, slightly different text preparation).
- Order: for English text the chunk order is clean in 35,591 of 35,596 cases (indexes 0..n−1, increasing offsets); only 25 chunks in 13 cases contain Indian-language script (to be marked as mixed-language). The other languages (Hindi etc., 1.1M−371k chunks) are not part of this plan.

So 2 projects: `lexbharat-sc-text` and `lexbharat-sc-vectors`.
