# Fonts for the PDF export
Noto Serif (Latin, Latin Extended) and Noto Serif Devanagari, from the Fontsource packages `@fontsource/noto-serif` and `@fontsource/noto-serif-devanagari` (version 5), regular and bold (Latin also italic and bold italic), WOFF format.
They are licensed under the SIL Open Font License 1.1 (full text in `OFL-NotoSerif.txt` and `OFL-NotoSerifDevanagari.txt`), which allows use, embedding in documents and redistribution with the licence kept. The fonts are not sold on their own and are not modified.
Why these: the standard PDF fonts have no rupee sign (U+20B9). The Latin file lacks it, the Latin-Extended and Devanagari files have it; the Devanagari file also covers Devanagari text for later Hindi drafts.
